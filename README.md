# XY-Knowledge-base
> 自用客服知识库系统，面向小型电商客服团队，快速检索业务话术与资料，支持本地/服务器部署

## ✨ 项目简介
XY-Knowledge-base 是一套**客服专属查询知识库**，专为小团队客服场景打造。使用 JSON 作为数据存储载体，轻量无重型数据库依赖，可本地直接启动，也能部署在云服务器对外提供服务。
内置简易账号权限管理、Bug与需求反馈面板、服务器运行状态监控、数据库维护工具。
实测 2核2G ECS 环境下单知识库可容纳 **2000+条目**，稳定支持 **20+并发访问**，满足小型电商客服团队日常查询使用。

> 项目代码由 DouBao turbo 模型辅助生成与迭代维护
> ⚠️ 注意：代码注释存在残留调试信息，正式上线维护前，请仔细检索清理多余注释与测试数据

## 📋 核心功能
- 📖 多样式知识库：支持多种知识库排版样式，适配话术、FAQ、产品资料等不同类型内容检索
- 🔍 快速查询：客服一键检索业务知识，提升应答效率
- 👤 简易账号管理：多账号登录，基础权限管控
- 💬 反馈收集：Bug上报 & 功能建议提交，后台统一查看管理
- 🖥️ 服务器监控：实时查看服务运行状态
- 🗂️ 数据库维护：内置工具，便捷维护 JSON 知识库数据
- 🚀 双部署模式：本地开发调试 / 云服务器线上部署

## 🧪 性能参考
- 最低推荐配置：2核 2GiB ECS云服务器
- 单知识库容量：支持 2000+ 知识条目
- 并发访问：稳定支持 20+ 用户同时在线查询
- 数据存储：原生 JSON 文件存储，无需 MySQL / PostgreSQL 等重型数据库

## ⚠️ 重要提醒
1. 本项目为**工作自用项目**，适合小团队内部使用，不建议直接用于高并发、对外公开的生产业务
2. 代码内包含AI生成遗留注释、调试残留内容，上线前务必全局检索并清理测试数据、冗余注释
3. JSON文件存储方式，适合中小体量知识库；如果后续数据量大幅上涨，建议迁移至数据库
4. 账号系统为简易实现，安全能力有限，部署公网请自行增加防护（反向代理、HTTPS、IP限制等）
